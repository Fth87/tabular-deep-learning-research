# Related work untuk eksperimen Task 3

Tabel ini memisahkan metode semi-supervised tabular dari augmentasi weak-to-strong yang dipakai dalam eksperimen. Kelemahan berikut adalah ringkasan praktis untuk konteks lima dataset yang akan dipilih; bukan klaim bahwa setiap paper melaporkan semua kelemahan tersebut.

## Augmentasi weak-to-strong

| Tahun | Augmentasi / sumber | Cara kerja | Contoh sederhana | Weak → strong untuk eksperimen | Kelemahan / catatan | Link |
|---|---|---|---|---|---|---|
| 2020 | VIME Swap Noise | Pilih fitur secara acak, lalu ganti nilainya dengan nilai dari kolom yang sama pada sampel lain. Pada paper VIME, corruption ini menjadi bagian dari tugas pretraining mask estimation dan value imputation. | Baris [20, 5, 7]; ganti fitur kedua dengan nilai kolom kedua dari baris lain → [20, 9, 7]. | Tingkatkan proporsi fitur yang diganti, misalnya 0.1 → 0.5. | Operator penggantian marginalnya tumpang tindih dengan SCARF. Untuk membandingkan operator di Task 3, tidak dibuat notebook duplikat; komponen pretraining VIME sendiri berbeda dan tidak diklaim telah diimplementasikan. | [NeurIPS 2020](https://proceedings.neurips.cc/paper/2020/hash/7d97667a3e056acab9aaf653807b4a03-Abstract.html) |
| 2022 | SCARF: Self-Supervised Contrastive Learning using Random Feature Corruption | Pilih subset fitur acak dan ganti tiap fitur terpilih dengan draw dari empirical marginal fitur tersebut. | [20, 5, 7, 2]; ganti fitur 2 dan 4 → [20, 9, 7, 5]. | Weak memilih lebih sedikit fitur daripada strong; Optuna memilih proporsinya. | Nilai per kolom dapat valid, tetapi kombinasi baris mungkin tidak realistis karena dependency antarfitur tidak dijaga. | [ICLR 2022](https://openreview.net/forum?id=CuV_qYkmKb3) |
| 2024 | Gaussian Noise — GsRCL untuk single-cell RNA-seq | Tambahkan noise Gaussian pada fitur numerik: x' = x + ε. | [0.20, -0.70, 1.10] + [0.04, -0.08, 0.02] → [0.24, -0.78, 1.12]. | Weak memakai σ kecil; strong memakai σ lebih besar. | Noise besar mengubah arti sampel. Sumber ini diteliti untuk single-cell RNA-seq, jadi penerapannya pada tabular umum perlu diuji. | [Oxford Academic 2024](https://academic.oup.com/bfg/article/23/4/441/7577350) |
| 2021 | Zero-out Noise — SubTab | Pilih fitur acak dan ubah nilainya menjadi nol. | [20, 5, 7, 2]; nolkan fitur 2 dan 4 → [20, 0, 7, 0]. | Weak men-zero-kan sedikit fitur; strong lebih banyak. | Nol dapat bermakna sebagai nilai nyata atau sebagai nilai standar setelah scaling. Tidak menjaga dependency antarfitur. | [NeurIPS 2021](https://proceedings.neurips.cc/paper_files/paper/2021/hash/9c8661befae6dbcd08304dbf4dcaf0db-Abstract.html) |
| 2025 | Range-Limited Augmentation — FeSTA / KDD | Pilih fitur dan sampel nilai baru dari rentang/bin lokal fitur tersebut. | Nilai 0.36 pada bin [0.25, 0.50] dapat menjadi 0.41, bukan nilai jauh seperti 0.90. | Weak mengubah sedikit fitur; strong mengubah lebih banyak fitur di dalam bin masing-masing. | Bergantung pada jumlah dan letak bin. Rentang lokal tetap tidak menjamin dependency lintas fitur terjaga. | [KDD 2025 DOI](https://doi.org/10.1145/3711896.3737098), [implementasi FeSTA](https://github.com/kyungeun-lee/festa) |
| 2025 | TabCutMix — ICML | Ambil donor dari kelas yang sama, lalu tukar subset fitur acak antara sampel penerima dan donor. | A [20, 5, 7, 2], B [30, 9, 6, 4], kelas sama; tukar fitur 2 dan 4 → [20, 9, 7, 4]. | Weak menukar sedikit fitur; strong menukar lebih banyak. | Pertukaran fitur individual dapat memutus hubungan antarfitur. Metode paper asal ditujukan untuk augmentasi pada tabular diffusion; adaptasi Task 3 adalah untuk pseudo-label consistency. | [ICML 2025](https://proceedings.mlr.press/v267/fang25f.html) |
| 2025 | TabCutMixPlus — ICML | Kelompokkan fitur yang berkorelasi, lalu tukar satu kelompok fitur sekaligus dengan donor dari kelas sama. | Tukar grup [income, tax, spending] bersama-sama, bukan mengganti satu fitur saja. | Weak menukar sedikit grup; strong menukar lebih banyak grup. | Perlu membentuk cluster fitur terlebih dulu. Implementasi Task 3 mengelompokkan fitur hasil encoding dengan korelasi Pearson sebagai pendekatan praktis; hasilnya tidak identik dengan prosedur fitur campuran pada paper. | [ICML 2025](https://proceedings.mlr.press/v267/fang25f.html) |

## Status metode di Task 3

| Metode | Status |
|---|---|
| TabCutMix | RankUp ordinal: weak/strong donor swap pada fitur terpilih |
| SCARF | RankUp ordinal: weak/strong feature replacement dari marginal train |
| Range-Limited | RankUp ordinal: weak/strong sampling di local quantile bin |
| Gaussian | RankUp ordinal: weak/strong noise pada fitur numerik |
| Zero-out | RankUp ordinal: weak/strong feature masking menjadi nol |
| TabCutMixPlus | RankUp ordinal: weak/strong swapping kelompok fitur berkorelasi |
| RankUp-CLS | Adaptasi klasifikasi nominal: cross-entropy pada labeled data dan pseudo-label consistency weak-to-strong; ARC ranking ordinal dihilangkan |
| VIME Swap Noise | Dicatat sebagai related work; adaptasi VIME ada di runner [`experiments/vime/run.py`](experiments/vime/run.py). |

Kelima dataset Task 2 mempertahankan urutan target dan memakai MAE sebagai metrik utama; RMSE, R², Spearman, dan QWK tetap dilaporkan sebagai metrik tambahan. Checkpoint RankUp ordinal dipilih berdasarkan validation MAE. Keenam augmentasi dijalankan dengan supervised pairwise rank loss dan pseudo-ranking weak/strong. Untuk klasifikasi nominal, RankUp-CLS memakai cross-entropy dan weak-to-strong multiclass pseudo-label consistency. Adaptasi ini tidak memakai ARC karena ARC asli membandingkan urutan target ordinal. Empat metode SSL pembanding juga dijalankan pada kedua kelompok dataset; target ordinal dipetakan ke level berurut untuk evaluasi. STUNT tetap menggunakan protokol prototypical few-shot.


## Status kode metode SSL pembanding

Kode sumber VIME, STUNT, GFTab, dan SSLAE berada di dalam folder eksperimennya masing-masing. `prepare_data.py` membentuk split bersama untuk lima dataset ordinal dan lima dataset klasifikasi. Enam eksperimen RankUp ordinal memiliki file mandiri di `experiments/rankup/`; enam eksperimen RankUp-CLS yang mandiri berada di `experiments/rankup_classification/`. Runner SSLAE, VIME, STUNT, dan GFTab mendukung kedua kelompok dataset dengan task yang sesuai.

Lima dataset lama memakai target ordinal numerik. Lima dataset OpenML dipakai untuk classification SSL dan CSV-nya berada di `dataset/classification/`. URL repo publik penulis ReCom dan SAWTab belum berhasil diverifikasi, sehingga keduanya belum diklon. Training model belum dijalankan.
